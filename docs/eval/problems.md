# P2 验证测试题

5 道题覆盖小学阶段典型抽象数学场景。每题跑 3 轮，评估 LongCat 生成 Three.js 代码的稳定性。

## 总览

| # | 主题 | 题目文本 |
|---|---|---|
| 1 | 旋转 | 一根长为12cm的木棒，按1:2的比例切分,切分点为O,现将木棒绕点O旋转180度，木棒扫过的面积为多少平方cm? |
| 2 | 行程 | 小明从A到B，每小时4km；小华从B到A，每小时6km。两人同时出发，A和B相距100km，多久后相遇？ |
| 3 | 工程 | 一个水池有两根管。甲管6小时注满，乙管4小时放空。两管同时开，多久注满？ |
| 4 | 几何分割 | 一个长方形长8cm宽6cm，从一角剪去一个边长2cm的正方形，剩余图形面积是多少？ |
| 5 | 分数 | 用图形表示 1/2 + 1/3 的过程和结果 |

## 期望行为（用于评分）

### 1. 旋转：木棒绕点旋转 180°
**正确答案**：40π ≈ 125.66 cm²（两个半圆：半径 4 + 半径 8）
**预期画面**：
- 一条 12cm 长的木棒（线段或细长 box）
- 在 1:2 处标记点 O
- 绕 O 旋转 180°（动画）
- 旋转过程中扫过的区域用半透明色填充
- 最终显示两个半圆形状（半径 4 和半径 8）

### 2. 行程：相遇问题
**正确答案**：10 小时（100 ÷ (4+6)）
**预期画面**：
- 两个角色（小明 + 小华）或两个移动的物体
- 从两端相向而行
- 动画显示移动过程
- 在中间某点相遇（具体相遇点取决于速度比）

### 3. 工程：水池注水
**正确答案**：永远不会注满（甲管注入速度 1/6/小时，乙管放出速度 1/4/小时，净流出 1/12/小时）
**预期画面**：
- 一个水池容器
- 两根管子（一根入水，一根出水）
- 动画显示水位变化（持续下降或标注"不会注满"）
- 数字标注管径流速

### 4. 几何分割：长方形剪正方形
**正确答案**：44 cm²（48 - 4）
**预期画面**：
- 一个 8×6 的长方形
- 一角剪去一个 2×2 的正方形（用阴影或缺失部分表示）
- 剩余部分用不同颜色显示
- 数字标注原面积和剪去面积

### 5. 分数：1/2 + 1/3
**正确答案**：5/6
**预期画面**：
- 两个饼图或矩形图，一个 1/2 一个 1/3
- 转换为共同分母 6：3/6 + 2/6
- 合并显示 5/6
- 颜色清晰区分分子分母

## 评分维度（详见 eval-rubric.md）

每道题每轮评分维度：

| 维度 | 满分 | 含义 |
|---|---|---|
| Clarity（清晰度）| 5 | 视觉是否清楚，10 岁孩子能不能跟着看懂 |
| Accuracy（准确性）| 3 | 数学/逻辑是否正确 |
| Sync with problem（贴合度）| 2 | 数字/参数是否真的从题目来（不是 LLM 自己编的）|
| **Total** | **10** | 7 = 通过 |

## 通过门槛

- 一次成功率 ≥ 60%：3/5 通过
- 含重试成功率 ≥ 90%：4-5/5 通过（设计文档目标）

注：MVP 设计文档计划是 4 个 LLM 各跑 3 轮 = 60 evals。MVP 阶段先跑 LongCat 5×3 = 15 evals 验证核心假设。
